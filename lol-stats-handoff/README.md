# 英雄联盟内战战绩站

一个用来记录 5v5 英雄联盟内战的小型工具：单文件网页 + 本地同步桥，自动从国服客户端拉取对局，按多维指标给每人打分、排名，并能按实力自动分队。

- **零依赖前端**：网站是一个 HTML 文件，双击就能用，数据存在浏览器本地。
- **自动同步**：通过本地桥读取国服客户端的 LCU 接口，一键拉取全部 5v5 峡谷自定义对局。
- **多维评分**：不判位置、不看胜负，同局 10 人内做百分位，兼顾 KDA、发育、视野和目标。
- **可分享**：导出带数据的 HTML 快照，发到群里别人直接就能看。

> 仅供朋友间的内战娱乐统计使用。与 Riot Games、腾讯无关。

不想装任何东西，直接打开快照：

website/lol_stats_snapshot_20261106.html

## 功能

### 排行榜

- 概览卡片：总对局、玩家数、最高评分、最高胜率。
- 排行表：玩家、场次、胜/负、胜率、KDA、综合评分；支持按评分 / KDA / 胜率排序和「最少场次」筛选。
- 对局历史：日期、胜方、双方阵容、每人 KDA / 英雄 / 位置，可编辑或删除。

### 录入与分队

- 红蓝各 5 人，填写 K/D/A、英雄、位置；同一玩家不能重复上场。
- 自动分队：按综合评分做蛇形选秀 + 两两交换优化，显示双方均分和实力差。
- 点击一名玩家再点另一队的玩家即可手动交换，分数实时重算。

### 数据

| 入口 | 作用 |
|---|---|
| 检测并同步客户端 | 调本地桥，先检查客户端进程和登录状态，再拉取全部可用对局并按 gameId 合并 |
| 导入 JSON 文件 | 同步的离线兜底；规则同上，只追加不覆盖 |
| 导出 / 导入 JSON | 完整状态备份与恢复（导入是**替换**） |
| 导出带数据 HTML | 生成内嵌当前数据的新文件，适合分享 |
| 清空所有数据 | 重置 |

同步回来的对局会自动补上评分指标（包括此前导入过的旧对局），补完立即重算排行。

## 多维评分

每局对 **10 名参与者**，把每个指标换算成局内百分位（0–1），这样长局短局、顺风逆风、英雄强弱都会被自动抵消。然后按四个维度等权平均、加权汇总：

| 维度 | 权重 | 指标 |
|---|---|---|
| 影响力 | 4 | KDA、参团率、助攻占比、治疗占比、分均控制、伤害占比、推塔伤害占比、目标伤害占比 |
| 发育 | 3 | 分均补刀、分均经济 |
| 视野 | 2 | 分均视野分、分均买真眼、分均排眼 |
| 目标 | 1 | 目标伤害占比、推塔伤害占比 |

单局得分：

```text
维度分  = 该维度内各指标百分位的平均值
加权分  = Σ(维度权重 × 维度分) / Σ维度权重
单局分  = (0.5 × 加权分 + 0.5 × 最强三项维度的均值) × 100
```

- **不含胜负**：只看表现，赢了也可能分低，输了也可能分高。
- **最强三项**：让辅助靠视野、坦克靠承伤、C 位靠输出各自都有得分路径。
- **总评 = 各局单局分的算术平均**，不做收缩；场次只作分母。
- 场次影响两处展示：同分时场次多者靠前；「最少场次」筛选只隐藏小样本，不改分数。
- 1 场和 27 场用同一套规则，小样本排名波动大是有意为之。

### 旧公式（回退）

手录对局或早期导入的对局没有 13 项指标时，自动回退到胜率 + KDA：

```text
winRate  = (wins + 2.5) / (games + 5)
kdaAvg   = (kdaSum + 20) / (games + 5)
rating   = (winRate × 0.5 + min(kdaAvg / 8, 1) × 0.5) × 100
```

一个玩家只要有一局带指标，就只按多维评分计算，两种算法不混算。

## 自动同步（需要国服客户端）

前提：Windows 上安装了国服英雄联盟客户端，并且已经启动、登录。

```bash
# 1. 安装依赖
python -m pip install -r scripts/requirements.txt

# 2. 注册 lolsync:// 协议（只需一次，之后网页按钮可以自动拉起本地桥）
python scripts/install_protocol.py

# 3. 打开网站，进入「数据」页，点「检测并同步客户端」
```

也可以手动常驻运行本地桥：

```bash
python scripts/lcu_server.py
# 或用 http://127.0.0.1:8765/ 直接打开由桥托管的网站
```

按钮的行为：

- 本地桥没启动 → 尝试通过 `lolsync://` 拉起；失败则显示「启动本地服务」按钮。
- 客户端没启动 / 没登录 → 明确提示，不改数据。
- 正常 → 显示召唤师名，拉取全部可用对局并合并。

> 升级 `lcu_sync.py` / `lcu_server.py` 后要**重启常驻的本地桥**，旧进程不会加载新代码。页面发现数据里没有评分指标时会给出提示。

### 离线导出 / 文件导入

```bash
python scripts/lcu_sync.py                 # 输出 data/lcu_sync.json
python scripts/lcu_sync.py --dry-run       # 只看结果不写文件
python scripts/lcu_sync.py --since 2026-10-01
python scripts/lcu_sync.py --no-rofl       # 不扫回放
```

然后在网站「数据」页点「导入 JSON 文件」选择生成的 JSON。

### 数据存在哪里

- 浏览器 `localStorage`，key 为 `lol-custom-stats-v1`。
- 用 `file://` 打开和用 `http://127.0.0.1:8765/` 打开是**两套独立数据**，建议固定用一种。
- 多标签页之间通过 `storage` 事件自动同步。

## 对局筛选规则

只导入满足以下全部条件的对局：

- `gameType = CUSTOM_GAME`
- `mapId = 11`（召唤师峡谷）且 `gameMode = CLASSIC`
- 正好 10 人，红蓝各 5
- 能确定胜方

海克斯大乱斗（`mapId=12` / `KIWI`）、练习模式、人数不足的对局都会被跳过。不能只看 `queueId`，自定义队列不止 3110。

## 本地桥接口

| 接口 | 说明 |
|---|---|
| `GET /api/health` | 存活检查 |
| `GET /api/status` | 客户端进程、登录状态、召唤师名 |
| `POST /api/sync` | 拉取全部可用对局，需带 `X-LCU-Sync: 1` 头 |

安全约束：

- 只绑定 `127.0.0.1`，不监听局域网或公网。
- CORS 只放行 `null`（`file://`）和 localhost 来源。
- 不返回、不打印认证 token。
- LCU 的 `verify=False` 只用于 `127.0.0.1` 的自签名证书，不要对外部地址关闭 TLS 校验。

## 已知限制

- 战绩列表只返回最近 **101 局**，没有日期过滤参数；更早的对局要靠 `.rofl` 回放兜底，而回放会过期。
- 自定义对局的位置字段不可靠，同步默认不写位置。
- 玩家按召唤师名匹配，改名会被当成新玩家；同名无法区分（没有 PUUID）。
- LCU 是客户端本地接口，国服版本更新后可能变化。
- 官方 Riot API 不覆盖国服，且自定义对局对普通 key 返回 404，所以走的是本机客户端。
- 综合评分是启发式指标，不是官方 MMR / ELO。
