从客户端同步

启动并登录英雄联盟客户端后，点击按钮自动检测并拉取全部可用的 5v5 峡谷自定义对局（海克斯大乱斗、练习模式等会被跳过）。按 gameId 合并，只追加新对局，不覆盖现有数据。

本地服务未启动时，按钮会尝试通过 lolsync:// 自动拉起。首次使用请运行一次 python scripts/install_protocol.py，也可以手动运行 python scripts/lcu_server.py。

多人怎么用？

浏览器安全限制不允许网页把数据直接写回 HTML 文件，所以战绩会保存在当前浏览器的 local storage 中。推荐流程：聚会时由一人负责录入；录完后点「导出带数据 HTML」，把新文件发到群里，其他人打开就能看到最新战绩。同一浏览器的多个标签页会自动同步。
